# E-commerce Data Analysis

## Project Overview
A beginner-friendly Data Analytics project using Python, Pandas, SQL, and CSV data to analyze e-commerce sales.

## Business Questions
- What is total revenue?
- How many orders and products were sold?
- Which category, city, and product generate the most revenue?
- Which payment method is used most?
- What is the average order value?
- Which city/category combinations perform strongly?

## Tools
- Python
- Pandas
- SQL
- CSV

## Files
- `ecommerce_sales.csv` — source dataset
- `ecommerce_analysis.py` — Python analysis
- `ecommerce_analysis.sql` — SQL queries
- `README.md` — documentation
- `category_revenue_summary.csv` — category results
- `city_revenue_summary.csv` — city results
- `product_revenue_summary.csv` — product results
- `monthly_revenue_summary.csv` — monthly results

## Run Python
Install Pandas:
```bash
pip install pandas
```
Run:
```bash
python ecommerce_analysis.py
```

## SQL
Import `ecommerce_sales.csv` into a table named `ecommerce_sales`, then run the queries in `ecommerce_analysis.sql`.

## Skills Demonstrated
CSV handling, Pandas DataFrames, calculated columns, grouping, aggregation, sorting, date analysis, SQL SELECT, GROUP BY, ORDER BY, aggregate functions, and subqueries.
